교랑(KYORANG) 템플릿 사용 안내
================================

1. 고치기
   - index.html 등 .html 파일을 메모장이나 VS Code 로 열어 글자를 바꾸면 됩니다.
   - 고칠 곳 위에는 ✏️ 주석을 달아 두었어요.
   - 색은 style.css 맨 위 :root { ... } 의 색 코드만 바꾸면 전체에 적용됩니다.
   - 사진은 같은 폴더에 넣고, 주석 안내대로 <img src="사진.jpg"> 또는
     background:url(사진.jpg) 로 바꾸세요.

2. 미리보기
   - index.html 을 두 번 클릭하면 브라우저에서 열립니다.

3. 인터넷에 올리기 (무료)
   - https://app.netlify.com/drop 에 이 폴더를 통째로 끌어다 놓으면 바로 주소가 생겨요.
   - 또는 Vercel, GitHub Pages 를 써도 됩니다.
   - 내 도메인(예: mycafe.com)은 각 서비스의 Domain 설정에서 연결하세요.

4. 문의 폼 (해당 템플릿만)
   - https://formspree.io 에서 무료 폼을 만들고, <form action="..."> 주소를 받은 주소로 바꾸면
     문의가 메일로 옵니다.

5. 라이선스
   - 구매하신 분이 자신의 사이트(또는 의뢰받은 사이트 1곳)에 쓸 수 있어요.
   - 템플릿 파일 자체를 다시 팔거나 배포할 수 없어요.
